# De l'enseignement à l'apprentissage

Une proposition de réforme de l'enseignement secondaire français, ouverte à la discussion paragraphe par paragraphe.

**Lire et commenter : [artemave.github.io/reforme-enseignement-secondaire](https://artemave.github.io/reforme-enseignement-secondaire/)**

## La proposition

Les classes sont surchargées, les enseignants manquent et beaucoup d'élèves décrochent. Plutôt que de réclamer toujours plus de moyens, le document pose une autre question : ne pourrions-nous pas mieux utiliser ceux dont nous disposons déjà ?

Il propose de conserver les programmes, les établissements et les enseignants, mais de changer la manière d'apprendre : chaque élève progresse à son rythme grâce à des ressources numériques et à un tuteur fondé sur l'intelligence artificielle, tandis que les enseignants supervisent et accompagnent plutôt que de faire cours. Le texte aborde aussi l'autonomie des élèves, l'évaluation, les devoirs, la journée scolaire, les infrastructures, les risques de la transition et les précédents existants.

## Participer

Chaque section et chaque paragraphe du document a sa propre discussion :

- **Lire** — aucun compte n'est nécessaire.
- **Commenter** — touchez la bulle à côté d'un passage (`+` s'il n'a pas encore de discussion, sinon le nombre de commentaires). Connectez-vous à GitHub et autorisez giscus, puis écrivez votre commentaire. Le premier commentaire sur un passage ouvre sa discussion.
- **Partager** — chaque passage a sa propre page, dont vous pouvez copier le lien.
- **Suivre** — utilisez « Subscribe » sur la page GitHub d'une discussion pour être notifié des réponses.

Les discussions sont hébergées dans les [Discussions GitHub](https://github.com/artemave/reforme-enseignement-secondaire/discussions) de ce dépôt ; vous pouvez aussi y participer directement. Seules les discussions ouvertes apparaissent sur le site, et un nouveau commentaire peut mettre quelques minutes à s'y afficher.

Le document évolue. Quand un passage est réécrit, ses discussions y restent rattachées tant qu'elles s'appliquent encore au texte ; sinon, elles restent consultables sur GitHub. Un lien vers une ancienne version d'un passage ramène au document actuel.
